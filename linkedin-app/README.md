# Vincent LinkedIn

Application PWA personnelle pour gérer le profil LinkedIn de Vincent Leclerc.

## Fonctions

- Tableau de bord responsive ordinateur et mobile.
- Propositions de publications complètes.
- Création depuis une visite, une tournée ou une expérience.
- Filtre local de confidentialité.
- Validation, modification et refus motivé.
- Calendrier éditorial.
- Statistiques de démonstration.
- Optimisation du profil et développement du réseau.
- Sauvegarde locale, export et import JSON.
- Installation comme application sur téléphone ou ordinateur.

## Hébergement

Cette version est hébergée sur GitHub Pages dans le dossier `/linkedin-app/`.

## Limites

Les connecteurs LinkedIn, Canva, CRM ITECK et PrestaShop nécessitent des autorisations externes. Les automatisations lorsque l’application est fermée nécessitent un backend.
